# Imdad-ul-Fuqaraa Trust website (React + Vite)
Run: `npm install` then `npm run dev`. Build: `npm run build` (output in `dist`). Deploy: import the GitHub repo in Vercel (framework: Vite).
Edit text, bank details, certificates and photo choices in `src/content.js`. Photos are in `src/assets`. Video is `public/women-skills-hub.mp4`.
Add a UPI QR: put `upi-qr.png` in `src/assets` and it appears on the Donate page. Donate page is `#/donate`.
Instagram photos/videos cannot be imported automatically. Download them, add to `src/assets`, then list them in `GALLERY`.
